# 名刺スキャナー

スマホのカメラで名刺を撮影 → Google ドライブの無料OCRで文字を読み取り、項目に自動で振り分け → 画面で確認・修正 → [名刺管理スプレッドシート](https://docs.google.com/spreadsheets/d/1jApTwQmymraPikdQAngU0UCyxiYi7L1bQZr9tRTzQHw/edit) の最終行に追記します。
「対応者」列には自動で **多良** が入ります。

Google Apps Script の Web アプリとして動くので、サーバーも API キーも不要・**完全無料**です。
項目の振り分けは簡易ルールなので、会社名・氏名などは追記前に画面で確認・修正してください。

## セットアップ（初回のみ・約5分）

1. スプレッドシートを開き、**拡張機能 → Apps Script** を開く
2. 左の「ファイル」に次の3つを作成し、このフォルダの内容をそれぞれ貼り付けて保存
   - `コード.gs`（最初からあるファイル）← `Code.gs` の内容
   - **＋ → HTML** で `index` という名前のファイル ← `index.html` の内容
   - ⚙ **プロジェクトの設定 →「appsscript.json」マニフェスト ファイルをエディタで表示する** にチェック → `appsscript.json` の内容
3. **デプロイ → 新しいデプロイ → 種類: ウェブアプリ**
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 自分のみ
   - 「デプロイ」→ 権限を許可
4. 表示された **ウェブアプリの URL** をスマホで開き、ホーム画面に追加しておくと便利です

## 使い方

1. 「📷 名刺を撮影する」をタップ → 名刺を撮影
2. 読み取り結果が表示されるので、誤りがあれば修正
3. 「スプレッドシートに追記」をタップ

## 列の対応について

スプレッドシートの上から30行の中で **見出し行**（会社名・名前・対応者など）を自動で探し、列を合わせます。書き込み先は表の中で最初に空いている行です（合計行などの下には書きません）。

| 読み取り項目 | 認識する見出しの例 |
|---|---|
| 会社名 | 会社名 / 会社 / 企業名 / 所属 |
| 部署 | 部署 / 部署名 / 部門 |
| 役職 | 役職 / 肩書 |
| 氏名 | 氏名 / 名前 / 担当者 |
| ふりがな | ふりがな / フリガナ |
| メール | メール / メールアドレス |
| 電話 | 電話 / 電話番号 / TEL |
| 携帯 | 携帯 / 携帯電話 |
| FAX / 郵便番号 / 住所 / URL | 同名の見出し |
| （対応者 = 多良） | 対応者 / 対応 / 営業担当 |
| （今日の日付） | 日付 / 登録日 / 交換日 |

- 対応する列が無い項目は「メモ」「備考」列にまとめて入ります
- シートが空の場合は見出し行を自動で作成します
- 先頭以外のシートに追記したい場合は `Code.gs` の `SHEET_NAME` にシート名を入れてください
- 対応者を変える場合は `Code.gs` の `RESPONDER` を変更して再デプロイしてください

## 読み取りのコツ

- 明るい場所で、名刺が画面いっぱいになるように真上から撮る
- 読み取りに使った一時ファイルは自動で削除されます
